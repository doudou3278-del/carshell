# 头蚊字 Dou · 车壳库（网页版）

由「头蚊字 Dou」微信小程序迁移而来的静态网站，部署在 GitHub Pages，无需服务器、无需续费。

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架 |
| `style.css` | 苹果风格界面（毛玻璃导航、分段控件、底部弹出卡片、滚动渐显） |
| `app.js` | 车壳库、详情、点赞榜、对比、收藏、搜索（⌘K）、电子调车板 |
| `board.js` | 调车板绘图，直接取自小程序 `utils/setup-board.js` |
| `data.js` | 车壳与评论数据快照（从云开发 `carShells` / `comments` 导出） |
| `img/` | 车壳封面、成品图、板件图、宽体扫描图（`*_s.jpg` 为缩略图） |

## 功能
- 概览：本周精选（视差）、最近收录 / 最多浏览 / 宽体专区横向货架、按车型浏览
- 车壳库：搜索、厂商与车型筛选、宽体筛选、排序、轴距/轮距范围筛选
- 车壳详情：图集 + 全屏看图、尺寸大字、按实测等比绘制的俯视图、评论、相近车壳；可下拉关闭
- 对比：最多 3 款并排对比，俯视轮廓叠放
- 电子调车板：从车壳库一键带入尺寸，双轴 5 cm 实尺校准，全屏
- 收藏、点赞、校准结果保存在本机浏览器

## 更新数据
数据是迁移时的快照（2026-11-12）。新增车壳：把图片放进 `img/`，在 `data.js` 的 `cars` 数组里按同样字段加一条即可。
